# 🎨 제너레이티브 아트 캔버스

마우스나 터치로 그리면 파티클이 잔상을 남기며 흩어지는 인터랙티브 드로잉 토이입니다. 순수 HTML/CSS/JavaScript(Canvas API)로만 만들어져 별도 설치나 빌드 과정이 필요 없습니다.

## 실행 방법

`index.html` 파일을 브라우저에서 열기만 하면 됩니다.

```bash
start index.html   # Windows
```

## 사용법

- **그리기**: 캔버스를 마우스로 드래그하거나 터치로 문지르면 파티클이 생성됩니다.
- **가만히 두기**: 조작이 없으면 파티클이 자동으로 화면을 떠다닙니다(ambient 모드).
- **브러시 크기 / 수명**: 왼쪽 패널의 슬라이더로 파티클의 크기와 잔상 지속 시간을 조절합니다.
- **색상 모드**: 레인보우, 파이어, 오션, 모노 중에서 선택합니다.
- **연결선(별자리 효과)**: 가까운 파티클끼리 선을 이어 별자리처럼 보이게 합니다.
- **지우기 / PNG 저장**: 캔버스를 초기화하거나 현재 그림을 PNG로 내려받습니다.

## 기술 스택

- HTML5 Canvas 2D API
- 바닐라 JavaScript (프레임워크 없음)
- CSS (반응형 UI, 다크 테마)
